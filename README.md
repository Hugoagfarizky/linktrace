# LinkTrace 🚀

> **Track Every Click. Understand Every Campaign.**

LinkTrace is a modern link management and campaign analytics SaaS platform. It converts standard URLs into high-performance trackable short links, providing privacy-conscious analytics and campaign attribution.

---

## 🌟 Key Features

- **Link Management:** Shorten URLs, assign custom aliases, configure status and expiration dates.
- **High-Performance Redirects:** Fast resolution and asynchronous event capture.
- **Privacy-Centric Analytics:** Aggregated visitor metrics, referrers, device/browser distributions, and geographic trends without invasive fingerprinting.
- **Campaign Organization:** Group links under marketing campaigns to compare channel performance.
- **UTM Builder:** Integrated generator for consistent UTM tracking parameters.
- **Multi-Workspace Support:** Workspace-level data isolation and management.

---

## 🛠️ Architecture & Tech Stack

- **Framework:** Next.js (App Router), React, TypeScript
- **Styling & UI:** Tailwind CSS, shadcn/ui, Lucide Icons
- **Visualizations:** Recharts
- **Database & ORM:** PostgreSQL, Prisma ORM
- **Validation:** Zod
- **Testing:** Vitest, Playwright
